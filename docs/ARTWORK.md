# Artwork provenance

The six demo covers and six generic control glyphs were generated by GPT-6 Astra via Codex CLI 0.156.1 using only the written [brief](ARTWORK_BRIEF.md). No source artwork, proprietary SVG paths, app resource bundle, external image, font file, actual album or lyric was supplied to that task. Generation completed successfully; its design notes are preserved in [ARTWORK_GENERATION.md](ARTWORK_GENERATION.md).

The maintainer inspected the source structures, sizes, local references and hashes; reviewed the artwork/icons in the browser; and replaced an invented label name with the descriptive text ORIGINAL STUDIES. The manifest records per-file hashes and review scope. Visual review is not a guarantee of uniqueness or an opinion about third-party rights.

The assets use ordinary SVG geometry and system font names, without bundled font software, raster illustrations, script, external links or embedded images. Generic control icons are intentionally simple functional geometry. Covers are fictional visual studies, not representations of real releases or artists.
