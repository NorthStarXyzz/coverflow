# Security

Report a suspected vulnerability using a GitHub private vulnerability report when available. Otherwise open an issue describing the affected API and impact without sharing secrets or exploit payloads that disclose private data.

Titles/subtitles use textContent, not HTML. The component only creates static project-owned SVG control shapes. Artwork protocols are allowlisted, referrers are suppressed, and failed resources show an owned placeholder. Host-provided URLs still cause browser image requests; the host must validate permitted destinations and any media/privacy requirements.

The package has no player API, account credential handling, analytics, persistent storage or media scraper. It does not sanitize a host’s unrelated HTML, control a host’s playback authorization, or grant rights to user-provided media.

Use `npm run verify` and keep the development tooling updated. Review SVG structure checks when accepting new assets.
