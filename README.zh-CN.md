# Coverflow

独立的 TypeScript / CSS 3D 封面浏览组件，无框架依赖，无运行时第三方依赖。

支持透视、侧面封面层叠、渐隐倒影、惯性拖动、滚轮、方向键、Home/End、稳定 ID 更新及宿主控制的播放状态。最多 15 张活跃卡片；动画停止后不持续安排帧循环；退出时释放监听和图像引用。

演示只使用本项目的原创矢量封面，播放是 UI 模拟，不连接音乐平台。

```sh
npm ci
npm run dev
npm run verify
```

通用接口、安装方式、许可证和来源说明见 [英文 README](README.md) 与 [API](docs/API.md)。

样式、图标与演示不依赖 Cider/Spotify 安装包，不包含真实专辑封面、歌词或录音。音乐平台接入及媒体使用权由宿主负责。项目采用 MIT，保留适用的第三方声明。
